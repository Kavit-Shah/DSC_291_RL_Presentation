# Reinforcement Learning Presentation (Marimo)

This project contains an interactive Marimo presentation in `presentation.py`.

## Quick Start

1. **Install dependencies**

   ```bash
   uv sync
   ```

2. **Open the presentation in Marimo editor**

   ```bash
   uv run marimo edit presentation.py
   ```

3. **Open the local URL** shown in your terminal (usually `http://127.0.0.1:2718`).

## Run Without Editing (Optional)

To run it as an app (read-only execution):

```bash
uv run marimo run presentation.py
```

## Requirements

- `uv` installed
- Python `3.12+` (handled automatically by `uv` based on `pyproject.toml`)
